# Garage Management System (Salesforce)

## Project Overview
This Salesforce-based Garage Management System manages appointments, vehicle services, billing, and customer communication efficiently, reducing manual effort and improving workflow.

## Features
- Appointment scheduling
- Vehicle and service tracking
- Billing and payment management
- Email notifications using Flow
- Data validation and duplicate prevention

## Technologies Used
- Salesforce CRM
- Apex (Triggers & Classes)
- Flow Automation
- Reports & Dashboards

## Key Implementations
- Custom objects: Customer, Appointment, Service Records, Billing
- Validation rules and duplicate rules to maintain data accuracy
- Apex trigger with handler class for dynamic service cost calculation
- Record-triggered Flow for payment update and email alerts
- Configured roles, profiles, and sharing settings for security
